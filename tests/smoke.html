Gym Log browser smoke test

Presses the app's real buttons in a real browser, so it checks what node tests/run.js cannot: that taps reach the right code. It opens the app in the frame below, 390 px wide.
It cannot touch your saved data. Before any app file loads, the frame's storage is replaced with an empty one in memory, the test stops if that replacement is not in place, and at the end it checks that this browser's real saved data is exactly as it was. GPS, the clock and the confirm boxes are stand-ins too.
To run it: in the repo folder run python -m http.server 8000, then open http://localhost:8000/tests/smoke.html. It runs by itself and takes a few seconds. It does not test a physical phone, real GPS, or the layout rules.
